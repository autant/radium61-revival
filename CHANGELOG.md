# Changelog

## 5.0.0 — première release candidate

- Application Windows Forms autonome « Radium61 Revival ».
- Transfert des messages du Radium 61 PID 1015 via WinUSB vers une sortie MIDI Windows.
- Interface graphique avec sélection et mémorisation de la sortie ; touches, vélocité, faders et potentiomètres vérifiés sur la machine de référence.
- **Distribution autonome multifichier validée** ; publication monofichier abandonnée car ne démarrait pas sur cette machine.
- Documentation bilingue, protocole observé et instructions de release ; aucun firmware M-Audio redistribué.

## Historique avant 5.0

- v4.4–4.6 : captures WinUSB et décodage expérimental à partir du endpoint 0x81.
- v4.7 : premier pont WinUSB → WinMM avec sortie audible.
- v4.8 : interface Windows Forms et fonctionnement continu.
- v4.9 : améliorations de robustesse et mémorisation des paramètres.
